how the forge works
s//01 ——- packer
[ ok ]

Drop loose PNG sprites. A MaxRects bin-packer arranges them with padding, edge extrude (kills mip-map seams), trim, optional 90° rotation and power-of-two sizes. Exports the atlas PNG plus engine-ready JSON.

s//02 ——- analyzer
[ ok ]

A flood-fill scan reads every pixel, groups connected sprites frame by frame, counts them, measures each frame's width × height, draws the bounding frames over the atlas and rebuilds the JSON — perfect for legacy or ripped sheets.

s//03 ——- json formats
[ ok ]

Phaser / TexturePacker hash, array or simple JSON with frame, rotation, trim + source-size data. Plugs straight into Phaser, PixiJS, Godot, Unity or your own engine loader.
